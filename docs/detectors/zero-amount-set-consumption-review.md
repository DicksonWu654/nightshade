# Zero-amount Set consumption review

Availability: default-on informational review. Requires complete ordinary histories
with exact collection, invocation and numeric evidence; gaps remain explicit.

This default informational rule reports a canonical unshielded send whose exact
modeled amount retains zero, on the same ordinary successful history as an earlier
required Set absence and exact-key insertion. The absence is enforced before
insertion, its collection revision remains current until insertion, and that
insertion survives through completion. Later removal or replacement followed by
reinsertion cannot restore the earlier certificate.

Resolved canonical calls and types select applicability. Immutable key and
collection-address evidence establishes equality; names, shared wildcard storage
paths and exclusive-branch effect unions do not. The rule reuses shared collection
consumption and numeric transfers. Matching work is bounded; unavailable histories,
operands and exhausted budgets diagnose incomplete analysis.

Zero-value sends and Set consumption can be intentional protocol no-ops. The rule
does not infer economic value or replay policy; review the purpose of the send
and key before treating the observation as a defect.
